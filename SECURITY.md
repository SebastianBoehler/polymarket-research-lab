# Security reports

Do not include private keys, API secrets, wallet exports, or sensitive account
activity in public issues or pull requests.

Report exploitable security defects through
[GitHub private vulnerability reporting](https://github.com/SebastianBoehler/prediction-market-research-lab/security/advisories/new)
when that feature is available. If it is unavailable, contact the maintainer
through the contact information on the
[GitHub profile](https://github.com/SebastianBoehler) before sharing sensitive details.

Include the affected commit, a minimal reproduction, and the impact. Never use
real credentials or funds in a reproduction. There is no guaranteed response
window or audited live-trading support.
